# ARC Web — iPhoneのホーム画面で使うAI

Apple Developerの有料登録やMacは不要です。7日ごとの再署名もありません。AIの推論は端末内で行い、AI APIの契約は使いません。

## 現在の状態

Webアプリ本体を作成しました。HTTPSサイトへの公開は、公開用ソースの送信が環境の自動承認に却下されたため未完了です。iPhoneから開ける公開URLはまだありません。

WebLLMへ切り替えた後の実モデルによる回答と、iPhone実機の音声・写真OCRは未確認です。

配布する `ARC-Web-app.zip` は、WebファイルをZIPの直下に置いています。`index.html`、JavaScript、CSS、画像、manifest、Service Worker、`.nojekyll`、この説明と検証メモを同梱しています。公開先の設定や認証情報は含めていません。

## 公開後のiPhone設定

1. 公開URLをiPhoneのSafariで開きます。
2. 共有ボタンから「ホーム画面に追加」を選び、「追加」を押します。
3. ホーム画面のARCを開き、Wi-Fi接続中に「AIを準備」を押します。
4. 初回に約300〜400MBのモデルをダウンロードします。準備完了後に質問を送信します。

端末の空きメモリやSafariのバージョンによって、準備や回答に時間がかかったり、AIを開始できない場合があります。無料AIには対応するSafariとGPU機能が必要です。非対応の端末でも、メモ・予定の機能を使えます。

## 使える機能

- 日本語での短いAI会話（Qwen2.5-0.5B-Instruct）。
- ボタンで始める音声入力、設定から有効にする読み上げ。対応しないブラウザーでは文字入力やiPhoneキーボードのマイクを使えます。
- 写真内の日本語・英語の文字の読み取り。画像全体や物体の理解には対応していません。写真の文字を入力欄で確認してから送信します。
- この端末のメモ保存。「覚えて 説明は短めに」でも保存できます。
- 日時リマインダー。「5分後に休憩を教えて」でも設定できます。ARCを開いている間だけお知らせし、閉じていた間の予定は次に開いたときに表示します。

小さなモデルなので、回答の正確さや長い会話の能力には限りがあります。最新の情報の検索、常時録音、他のiPhoneアプリの自動操作には対応していません。

## データ

会話、メモ、予定はこのブラウザー内に保存します。AI会話や写真は推論サーバーへ送りません。音声入力はブラウザーの音声認識機能を使い、設定や機種により音声がApple等のサービスへ送られる場合があります。初回のモデルと読み取り用データは公開CDNから取得します。写真の文字読み取り時は空きメモリを確保するためAIを停止し、会話時に再読み込みします。

ブラウザーの保存データを消すと履歴やメモが消えます。Safariとホーム画面アプリで保存領域が異なる場合があります。非公開サイトの認証を保つため、Web画面のオフライン配信は行いません。モデルデータのキャッシュには保存容量が必要です。

## 無料の意味

Appleの年会費とAI API利用料金はありません。通信料と既存の端末・回線は必要です。公開には無料枠のあるHTTPSホスティングを使用します。公開コードに会話、写真、メモ、秘密情報を含めません。
